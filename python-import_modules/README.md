# Python - Import Modules

## Task 0: Import and Add
Created `0-add.py` to import the `add` function and print the result of adding 1 and 2.

## Python - Import Modules

This directory contains Python scripts that demonstrate importing modules, using command-line arguments, and working with compiled Python modules.

### 0. Import a function

**File:** `0-add.py`

Import the `add` function from `add_0.py`, assign the values `1` and `2` to variables, and print their sum in the required format.

**Example output:**

```text
1 + 2 = 3
```

### 1. My first toolbox!

**File:** `1-calculation.py`

Import the arithmetic functions `add`, `sub`, `mul`, and `div` from `calculator_1.py`. Perform addition, subtraction, multiplication, and division using the values `10` and `5`.

### 2. How many arguments?

**File:** `2-args.py`

Display the number of command-line arguments passed to the script, followed by each argument and its position.

**Example:**

```bash
./2-args.py hello world
```

```text
2 arguments:
1: hello
2: world
```

### 3. Infinite addition

**File:** `3-infinite_add.py`

Add all integer arguments passed through the command line and print the total.

**Example:**

```bash
./3-infinite_add.py 1 2 3
```

```text
6
```

### 4. Who are you?

**File:** `4-hidden_discovery.py`

Import the compiled module `hidden_4.pyc` and print its names that do not begin with double underscores, in alphabetical order.

### 5. Everything can be imported!

**File:** `5-variable_load.py`

Import the variable `a` from `variable_load_5.py` and print its value.

**Expected output:**
