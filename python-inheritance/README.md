# python-inheritance

Inheritance and introspection in Python.

| File | Description |
|------|-------------|
| `0-lookup.py` | Function `lookup(obj)` that returns the list of available attributes and methods of an object |
| `1-my_list.py` | Class `MyList` that inherits from `list` and has a `print_sorted()` method |
| `tests/1-my_list.txt` | Doctest file for `1-my_list.py` |
| `2-is_same_class.py` | Function `is_same_class(obj, a_class)` that returns True if the object is exactly an instance of the class |
