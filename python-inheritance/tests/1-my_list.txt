Test for 1-my_list.py
=====================

Import the class:

>>> MyList = __import__('1-my_list').MyList

Example from the task (the original list must not change):

>>> my_list = MyList()
>>> my_list.append(1)
>>> my_list.append(4)
>>> my_list.append(2)
>>> my_list.append(3)
>>> my_list.append(5)
>>> print(my_list)
[1, 4, 2, 3, 5]
>>> my_list.print_sorted()
[1, 2, 3, 4, 5]
>>> print(my_list)
[1, 4, 2, 3, 5]

Empty list:

>>> empty = MyList()
>>> empty.print_sorted()
[]

Single element:

>>> one = MyList([7])
>>> one.print_sorted()
[7]

Already sorted:

>>> ordered = MyList([1, 2, 3])
>>> ordered.print_sorted()
[1, 2, 3]

Reverse order:

>>> backwards = MyList([3, 2, 1])
>>> backwards.print_sorted()
[1, 2, 3]

Negative numbers and zero:

>>> mixed = MyList([3, -1, 0, -5])
>>> mixed.print_sorted()
[-5, -1, 0, 3]

Duplicates:

>>> dupes = MyList([2, 1, 2])
>>> dupes.print_sorted()

>>> print(MyList([2, 1]).print_sorted())
