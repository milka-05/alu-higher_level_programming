# python-more_classes

More on classes and objects in Python.

| File | Description |
|------|-------------|
| `0-rectangle.py` | Empty class `Rectangle` that defines a rectangle |
| `1-rectangle.py` | Class `Rectangle` with validated private `width` and `height` (getters and setters) |
| `2-rectangle.py` | Class `Rectangle` with validated `width` and `height`, plus `area()` and `perimeter()` methods |
| `3-rectangle.py` | Class `Rectangle` with area, perimeter, and a `__str__` that draws the rectangle with `#` |
| `4-rectangle.py` | Class `Rectangle` with area, perimeter, `__str__` drawing with `#`, and an `eval()`-able `__repr__` |
| `5-rectangle.py` | Class `Rectangle` that prints `Bye rectangle...` when an instance is deleted |
| `6-rectangle.py` | Class `Rectangle` with a public class attribute `number_of_instances` that tracks live instances |
| `7-rectangle.py` | Class `Rectangle` with a public class attribute `print_symbol` used to draw the rectangle |
| `8-rectangle.py` | Class `Rectangle` with a static method `bigger_or_equal` that returns the rectangle with the bigger area |
| `9-rectangle.py` | Class `Rectangle` with a class method `square` that returns a new square Rectangle |
