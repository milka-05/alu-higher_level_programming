# python-everything_is_object

Exploring how everything in Python is an object.

| File | Description |
|------|-------------|
| `0-answer.txt` | Name of the function used to print the type of an object |
| `1-answer.txt` | Name of the function used to get the identifier (memory address in CPython) of a variable |
| `2-answer.txt` | Whether `a = 89` and `b = 100` point to the same object (Yes or No) |
| `3-answer.txt` | Whether `a = 89` and `b = 89` point to the same object (Yes or No) |
| `4-answer.txt` | Whether `a = 89` and `b = a` point to the same object (Yes or No) |
| `5-answer.txt` | Whether `a = 89` and `b = a + 1` point to the same object (Yes or No) |
| `6-answer.txt` | Output of comparing `s1 == s2` after `s2 = s1` |
| `7-answer.txt` | Output of `s1 is s2` after `s2 = s1` |
| `8-answer.txt` | Output of `s1 == s2` for two separately created equal strings |
| `9-answer.txt` | Output of `s1 is s2` for two separately created equal strings |
| `10-answer.txt` | Output of `l1 == l2` for two separately created equal lists |
| `11-answer.txt` | Output of `l1 is l2` for two separately created equal lists |
| `12-answer.txt` | Output of `l1 == l2` after `l2 = l1` |
| `13-answer.txt` | Output of `l1 is l2` after `l2 = l1` |
| `14-answer.txt` | Output of printing `l2` after `l1.append(4)` when `l2 = l1` |
| `14-answer.txt` | Output of printing `l2` after `l1.append(4)` when `l2 = l1` |
