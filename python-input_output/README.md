# python-input_output

Reading and writing files in Python.

| File | Description |
|------|-------------|
| `0-read_file.py` | Function `read_file(filename="")` that reads a UTF8 text file and prints it to stdout |
| `1-write_file.py` | Function `write_file(filename="", text="")` that writes a string to a UTF8 file and returns the number of characters written |
| `2-append_write.py` | Function `append_write(filename="", text="")` that appends a string to a UTF8 file and returns the number of characters added |
| `3-to_json_string.py` | Function `to_json_string(my_obj)` that returns the JSON representation of an object as a string |
| `4-from_json_string.py` | Function `from_json_string(my_str)` that converts a JSON string into a Python object |
| `5-save_to_json_file.py` | Function `save_to_json_file(my_obj, filename)` that writes an object to a text file using JSON representation |
| `6-load_from_json_file.py` | Function `load_from_json_file(filename)` that reads a JSON file and returns the corresponding Python object |
| `7-add_item.py` | Script that adds command-line arguments to a list and saves the list in `add_item.json` using JSON functions |
